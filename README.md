# Mael Portfolio

Bienvenue sur le dépôt de mon portfolio personnel de développeur web.

Ce projet a pour objectif de présenter mon parcours, mes compétences et les différents projets que j'ai réalisés au cours de ma formation et de mon apprentissage du développement web.

Conçu avec **React, Three.js et Sass**, ce portfolio est également un espace d'expérimentation dans lequel je peux explorer de nouvelles technologies, travailler mes compétences et exprimer ma créativité.

Il reflète mon approche du développement web : **allier simplicité, performance et expériences interactives**.
